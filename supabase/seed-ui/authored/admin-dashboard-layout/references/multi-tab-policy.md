# 多标签页（Tab）的完整状态模型

多标签页是后台最容易「看起来简单、做起来失控」的组件。它同时和路由、缓存、持久化三件事纠缠。
本文给出可直接落地的状态模型与淘汰规则。

## 一、什么时候该做多标签页

**该做**：用户需要在多个列表/详情之间来回对照（客服工单、订单审核、多店铺管理）。
**不该做**：单层工具型后台（只看监控、只做一次配置）。硬加多标签页只会占掉 40px 高度还让人困惑。

判断标准：如果用户的操作路径里频繁出现「回到列表再进另一条」，就该做；
如果用户 90% 的时间停在一个页面里，就不该做。

## 二、Tab 的字段模型

```ts
type Tab = {
  path: string;        // 唯一键，用规范化后的路由 path（不含 query 的筛选参数）
  title: string;       // 显示名，取自路由 meta，不要截断成 6 个字符
  icon?: string;       // 可选，与侧栏图标一致，便于快速定位
  pinned: boolean;     // 固定，永不淘汰
  closable: boolean;   // 首页等核心页可设 false
  lastVisited: number; // 时间戳，用于 LRU 淘汰
};
```

**关键点**：`path` 只包含「页面身份」，不含筛选/分页 query。
`/orders?status=paid&page=3` 和 `/orders?status=refund` 应该是**同一个 Tab**，
否则用户改两次筛选就开出一排重复标签。筛选状态属于页面内部状态，不属于 Tab 身份。

## 三、淘汰规则（LRU + 两条豁免）

```
候选淘汰集 = 全部 Tab
           − pinned 的
           − 当前激活的
           − 刚打开的这个
按 lastVisited 升序取第一个淘汰
```

- 上限取 **8**。低于 6 会让多任务用户频繁被关；高于 10 后标签条开始横向滚动，
  滚动的标签条比没有标签条更难用。
- 淘汰时给 toast：`已关闭最久未访问的「订单 1024」`。静默关闭会被当成 bug。
- 如果候选淘汰集为空（比如 8 个全是 pinned），则**允许超限**，并把标签条切换为横向滚动模式。

## 四、关闭行为

| 操作 | 结果 |
| --- | --- |
| 关闭非当前 Tab | 当前 Tab 不变，焦点回到该 Tab 位置 |
| 关闭当前 Tab | 激活**左邻** Tab（没有左邻则激活右邻），不是首页 |
| 关闭最后一个 Tab | 跳到首页或工作台 |
| 关闭有未保存内容的 Tab | 弹确认框（见 crud-page-patterns 的离开拦截） |
| 中键点击 Tab | 关闭该 Tab（浏览器习惯，用户会期待） |

## 五、持久化

刷新页面后 Tab 应该还在，这是多标签页的核心价值。

```ts
// 写入 sessionStorage（不要 localStorage）
sessionStorage.setItem('admin.tabs', JSON.stringify({
  tabs: tabs.filter(t => !t.transient),   // 不持久化「临时」标签（如某次搜索中间页）
  active: activePath,
}));
```

- 用 `sessionStorage` 而不是 `localStorage`：换一个浏览器标签页开后台，应该是一个干净的新会话。
- 持久化时**只存 path + title + pinned**，不存页面数据。数据靠路由重新拉取，避免存了过期数据。
- 恢复时要校验权限：用户权限可能变了，恢复出来的 Tab 若已无权访问，直接剔除并提示。

## 六、和路由的同步

- 打开 Tab = 路由变化时，若目标路由不在 Tab 列表中，则新增。
- 关闭 Tab = 从列表移除；若关的是当前页，先 `navigate` 到左邻再移除，避免出现「路由指向已关闭 Tab」的中间态。
- 不要在 `useEffect` 里无脑把每次路由变化都加进 Tab，那会把 404 页、登录页也加进去。
  维护一个**白名单**或**路由 meta 标记**（`meta.tab: true`）。

## 七、视觉规格

| 项 | 取值 |
| --- | --- |
| 标签条高度 | 40px |
| 单个 Tab 最大宽 | 180px，超出 `text-overflow: ellipsis` |
| Tab 内边距 | 左右 12px |
| 关闭按钮热区 | 20×20，hover 才显示 |
| 激活态 | 背景 `#fff` + 底部 2px 主色条（或背景 `#eef4ff`） |
| 未激活态 | 背景 `#f2f3f5`，文字 `#4b5563` |
| 固定 Tab | 左侧一个 12px 图钉图标，无关闭按钮 |
| 右键菜单 | 「关闭当前 / 关闭其他 / 关闭右侧 / 全部关闭 / 固定」 |

右键菜单是重度用户的效率入口，「关闭其他」应该被高频使用 —— 如果没人用，说明标签条本身设计得不对。
