# 商品卡规格

商品卡是电商里出现次数最多的组件。同一个商品可能出现在
列表页、搜索页、推荐位、购物车、订单详情里，**每处的信息密度不同**，
但视觉语言必须一致，否则用户会觉得换了产品。

## 一、四种卡片规格

### S 型 · 横向紧凑（用于购物车、订单、推荐横滑）

```
[img 80×80]  标题最多 2 行
             规格：藏青 / L
             ¥399    ×1
```

- 图片 72–88px 方形
- 标题 14px，最多 2 行
- 价格 16px，靠右下
- 卡片高度约 96–104px

### M 型 · 标准网格（列表页、搜索结果）

- 图片 1:1 或 3:4
- 桌面 4–5 列，平板 3 列，移动 2 列
- 信息：图片 → 标题（2 行）→ 价格 → 辅助信息（销量/好评率）
- 卡片宽 220–280px（桌面）
- 卡片间距 16–20px（桌面）/ 12px（移动）

### L 型 · 大图卡片（首页推荐、活动页）

- 图片 4:3 或 16:9
- 桌面 2–3 列
- 可额外放：卖点短句、标签、评价摘要
- 卡片宽 320–420px

### 横滑型（用于「猜你喜欢」「最近浏览」）

- 卡片宽 `78vw`（移动）/ `240px`（桌面）
- `overflow-x: auto; scroll-snap-type: x mandatory;`
- 子项 `scroll-snap-align: start;`
- 首屏必须露出下一张的边缘 **15–20%**，否则用户不知道可以滑
- 隐藏滚动条（`scrollbar-width: none`），但要保留键盘与触控滚动

## 二、信息优先级

同屏只允许出现以下信息，按优先级取舍（超出就砍）：

| 优先级 | 信息 | 是否必放 |
| --- | --- | --- |
| 1 | 商品图 | 必须 |
| 2 | 现价 | 必须 |
| 3 | 标题 | 必须 |
| 4 | 划线原价 | 有真实原价时必放 |
| 5 | 促销/库存标签 | 最多 1 个（同屏总计 ≤ 2） |
| 6 | 销量 / 好评率 | 二选一 |
| 7 | 规格摘要（`3 色可选`） | 服饰类可放 |
| 8 | 品牌 / 店铺名 | 仅搜索结果需要 |

**不要**在卡片上放：收藏按钮（除非是收藏页）、评分星级（除非品类强依赖评分）、
多个促销标签堆叠、`立即购买` 按钮（卡片整体可点即可）。

## 三、图片规范

```css
.pcard__media {
  aspect-ratio: 1 / 1;         /* 或 3 / 4，全站统一 */
  overflow: hidden;
  border-radius: 8px;
  background: #f5f5f5;         /* 图片加载前占位，避免白闪 */
}
.pcard__media img {
  width: 100%; height: 100%;
  object-fit: cover;
  transition: transform .3s ease;
}
.pcard:hover .pcard__media img { transform: scale(1.04); }  /* 桌面 hover 轻微放大 */
```

- 主图**不要加文字水印**（促销文案用 HTML 标签叠，不要烧进图里），
  否则图片无法复用到其他场景
- 移动端 `<img loading="lazy" decoding="async">`；
  **首屏前 4 张不要 lazy**，否则首屏白图
- 用 `srcset` 出 200/400/800 三档宽度，移动端不要下 800px 的图
- 图片必须写 `alt`，内容是「商品名 + 关键规格」，
  如 `alt="轻量羽绒外套 藏青"`，不要写 `alt="商品图"`

## 四、价格排版

```html
<div class="pcard__price">
  <span class="pcard__now"><i>¥</i><b>399</b></span>
  <s class="pcard__was">¥599</s>
</div>
```

```css
.pcard__now { color: var(--price-red); font-variant-numeric: tabular-nums; }
.pcard__now i { font-size: .62em; font-style: normal; margin-right: 1px; }
.pcard__now b { font-size: 22px; font-weight: 700; line-height: 1; }
.pcard__was { font-size: 13px; color: #999; margin-left: 6px; }
```

要点：

- 货币符号 `¥` 比数字小（约 0.6 倍），这是中文电商的惯例，能让数字更突出
- 数字用 `tabular-nums`，同列价格在垂直方向对齐
- 千分位：`¥1,299`，四位以上必须加分隔
- 划线价用 `<s>` 标签（语义正确），不要用 `text-decoration` 加在 `<span>` 上

## 五、标签系统

```html
<span class="tag tag--promo">限时直降</span>
<span class="tag tag--stock">仅剩 3 件</span>
```

| 类型 | 颜色 | 文案示例 |
| --- | --- | --- |
| 促销 | 品牌红底白字 | `满 300 减 50`、`限时直降` |
| 库存 | 橙色或红色描边 | `仅剩 3 件`、`已售 87%` |
| 新品 | 品牌色描边 | `新品`、`首发` |
| 服务 | 灰色描边 | `包邮`、`7 天无理由` |

规范：

- 高度 18–20px，字号 11–12px，内边距 4–6px，圆角 2–4px
- 图片上的标签放在左上角，距边 8px
- 标签**不要半透明叠在复杂图上**，对比度无法保证；用实底
- 同屏标签 ≤ 2 个。超过就把次要标签挪进详情页

## 六、列表页的加载与空态

- 骨架屏：**延迟 200ms 再出现**。请求在 200ms 内返回时不显示骨架屏，
  否则会闪一下，比空白更糟
- 骨架屏的卡片数与实际列数一致，尺寸与真实卡片一致（避免布局跳动）
- 首屏加载 12–20 个商品，滚动到底前 300px 触发下一页
- 空态要给出**可执行动作**：`没找到相关商品，试试「羽绒服」` + 热门搜索词
- 筛选无结果时提供「清除筛选条件」按钮，不要只显示一句「暂无数据」

## 七、常见反模式

| 反模式 | 症状 | 修法 |
| --- | --- | --- |
| 卡片高度不固定 | 列表出现「瀑布流」式参差，扫描困难 | 标题固定 2 行截断 + 图片固定比例 |
| 标题不限行数 | 长标题把价格推到卡片外 | `-webkit-line-clamp: 2` |
| 卡片上放「加入购物车」按钮 | 移动端误触率高，且与进入详情冲突 | 卡片整体可点，加购在详情页 |
| 图片用 `background-image` | 无法 `srcset` 自适应，无法 lazy，LCP 差 | 用 `<img>` + `object-fit` |
| 划线价与现价同色 | 视觉上分不清哪个是实付 | 划线价灰色，现价品牌色加粗 |
| 标签堆到 4 个 | 用户判定套路，说服力转负 | 最多 2 个，其余进详情 |
| 首屏图片也 lazy | 首屏白图，LCP 严重恶化 | 首屏前 4 张 `loading="eager"` |
| 骨架屏立即出现 | 快速网络下闪烁，观感更差 | 延迟 200ms |
