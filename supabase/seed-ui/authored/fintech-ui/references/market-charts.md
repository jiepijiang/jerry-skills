# 行情图表与专业数据组件

行情类组件（K 线、分时、盘口、深度图）有很强的专业惯例。
用户已经形成了肌肉记忆，**任何「创新」都会被当成 bug**。
这一节讲怎么把这些组件做对。

## 一、分时图（当日走势）

### 必含元素

1. 昨收价基准线（虚线，灰色）
2. 价格线（按涨跌染色，与列表涨跌色一致）
3. 面积填充（价格线下方到基准线之间，透明度 0.1–0.15）
4. Y 轴：左侧显示价格，范围以昨收为中心对称展开
   （例如昨收 100，最高涨 3%，最低跌 1%，则 Y 轴取 97–103，**对称**）
5. X 轴：交易时段刻度（`9:30 / 11:30 / 13:00 / 15:00`）
6. 成交量柱（图下方，高度占整体 20–25%）

### 关键规则

- **Y 轴必须对称于昨收**，否则涨跌的视觉幅度会被扭曲，
  这是行情图里最容易犯的错
- 十字光标（crosshair）：长按/悬停出现，跟随手指，
  显示 `时间 / 价格 / 涨跌幅 / 成交量`
- 十字光标的信息浮层**不要遮住手指所在区域**，放在图的另一侧
- 空数据（未开盘）显示「今日休市」，不要画一条平线
- 刷新频率：分时图 3–5 秒轮询即可，**不要做 1 秒级实时**，
  流量和电量成本不划算，且视觉闪烁

## 二、K 线图

### 单根 K 线的绘制

```
        ┃  ← 上影线（最高价）
      ┌─┴─┐
      │   │ ← 实体（开盘价 ~ 收盘价）
      └─┬─┘
        ┃  ← 下影线（最低价）
```

- 阳线（收 > 开）：红，实体填充
- 阴线（收 < 开）：绿，实体填充（部分软件用空心，需在设置里可选）
- 十字星（开 = 收）：一条横线，宽度 = 实体宽度
- 影线宽度 = 实体宽度的 1/3，最小 1px（低于 1px 会因像素对齐闪烁）

### 周期与均线

- 周期切换：`分时 / 5分 / 15分 / 30分 / 60分 / 日 / 周 / 月`，
  用横向可滚动的 tab，**默认选中「日」**
- 均线：`MA5 / MA10 / MA20 / MA60`，颜色需在图例里标明。
  均线颜色不要用红绿（会和涨跌冲突），用蓝 / 橙 / 紫 / 青
- 图例放在图上方一行，格式：`MA5 12.34  MA10 12.18`，
  数字用 `tabular-nums`

### 交互

- 双指捏合缩放，单指拖动平移
- 长按出十字光标 + 浮层（浮层显示该根的 `开/高/低/收/涨跌幅/成交量`）
- 缩放时**保持右边缘锚定**（最新的 K 线始终在右侧），
  这是所有行情软件的行为，不要改成以中心缩放
- 缩放到极限时给一次轻微反馈（`scroll-snap` 或 1px 回弹），不要静默失效

## 三、盘口 / 五档

```
卖五   12.35   1,200
卖四   12.34     800
卖三   12.33   2,100
卖二   12.32     450
卖一   12.31   1,900
──────────────────────
买一   12.30   2,300
买二   12.29   1,100
买三   12.28     600
买四   12.27     900
买五   12.26   1,500
```

- 三列：档位、价格、数量。价格和数量**右对齐 + 等宽数字**
- 卖档红、买档绿（涨红跌绿体系下，卖盘在上用红、买盘在下用绿）
- **背景条**：用与文字同色的浅色背景条表示数量占比，
  条宽 = 数量 / 最大数量。这是盘口最重要的视觉信息
- 中间一行显示最新价与涨跌幅，字号比档位大一号
- 点击某一档可直接填入下单价格（可选功能，需明确提示）

## 四、表格化行情列表

用于自选股、持仓、排行榜。列优先级的取舍：

| 列 | 是否常驻 | 说明 |
| --- | --- | --- |
| 名称 + 代码 | 是 | 左对齐，代码用次级色小字 |
| 最新价 | 是 | 右对齐，涨跌染色 |
| 涨跌幅 | 是 | 右对齐，带符号，**最常被扫描的一列** |
| 涨跌额 | 移动端可隐藏 | |
| 成交量 / 成交额 | 桌面常驻 | 需带单位（`万` / `亿`） |
| 换手率 / 市盈率 | 桌面可选 | 默认隐藏，进「自定义列」 |

规则：

- 移动端最多 4 列（名称、最新价、涨跌幅、成交额），
  其余进「自定义列」设置
- 涨跌幅列宽度固定（约 72–80px），因为格式固定（`+10.00%`）
- 名称列 `min-width: 140px`，支持点击进入详情
- 排序：点击表头切换 `降序 → 升序 → 取消`，当前排序列要有箭头指示
- 行情列表**不做骨架屏闪烁**，用上一次缓存的数据渲染，
  数据回来后原地更新数字（避免列表跳动）
- 数字更新时给一次 **150–200ms 的背景色脉冲**（`#fff3cd` → 透明），
  帮助用户注意到变化。脉冲不能用红绿（会和涨跌语义混淆）

## 五、涨跌色与无障碍

```css
:root { --up: #e5342a; --down: #0aa06e; }
[data-color-scheme="intl"] { --up: #0aa06e; --down: #e5342a; }
```

- 提供设置项：`涨跌颜色：中国惯例（红涨） / 国际惯例（绿涨）`
- 存储在 `localStorage`，首屏渲染前应用（避免闪一下再变色）
- 即使换了配色，**箭头和正负号不变**：涨永远是 `▲` 和 `+`
- 色盲友好模式（可选）：上涨用 `▲` + 红色加下划线，下跌用 `▼` + 绿色

## 六、常见反模式

| 反模式 | 症状 | 修法 |
| --- | --- | --- |
| 分时图 Y 轴不对称 | 涨 1% 和跌 1% 看起来幅度不同，误导判断 | 以昨收为中心对称取值 |
| K 线缩放到极限无反馈 | 用户以为卡死，反复捏合 | 保持右锚定 + 边界回弹 |
| 行情数字用比例字体 | 数字跳动时列宽变化，整行抖动 | `tabular-nums` |
| 每秒刷新分时图 | 电量与流量浪费，视觉闪烁 | 3–5 秒轮询 |
| 均线用红绿 | 与涨跌色冲突，无法分辨哪条是均线 | 用蓝/橙/紫/青 |
| 数字更新用红绿脉冲 | 被误解为涨跌 | 用中性色（浅黄/浅灰）脉冲 |
| 移动端行情表 8 列 | 必须横向滚动，且文字被压到不可读 | 4 列常驻 + 自定义列 |
| 涨跌只上色不给符号 | 色盲用户无法分辨 | 颜色 + 符号双通道 |
