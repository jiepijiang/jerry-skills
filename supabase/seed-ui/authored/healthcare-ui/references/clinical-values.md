# 临床数值：范围、单位与危急值

这一份是给前端做校验和展示用的参考表。
**它不是医学建议**，阈值只用于界面校验与提示分级；
上线前必须由产品的临床负责人确认。

## 一、三层阈值模型

| 层级 | 含义 | 界面行为 |
| --- | --- | --- |
| 医学可能范围 | 生理上可能出现的极值 | 超出则**硬报错**，不允许提交 |
| 正常参考范围 | 一般人群的正常区间 | 超出则**提示**，用户确认后可提交 |
| 危急值 | 需要立即医疗干预 | 顶部红色横幅 + 阻止提交 + 建议联系医生 |

**关键原则**：硬报错只能用在「物理上不可能」的区间。
把「高血压」当成输入错误拒绝，等于让患者无法记录真实病情。

## 二、常用指标参考

### 血压（mmHg）

| 层级 | 收缩压 SBP | 舒张压 DBP |
| --- | --- | --- |
| 医学可能 | 50 – 300 | 30 – 200 |
| 正常参考 | 90 – 139 | 60 – 89 |
| 危急值 | ≥ 180 或 ≤ 90 | ≥ 120 或 ≤ 60 |

界面注意：

- 血压必须**成对录入**（SBP/DBP），且校验二者关系：
  `SBP` 应大于 `DBP`，否则报错 `收缩压应高于舒张压`
- 展示格式 `120/80 mmHg`，中间用斜杠，不留空格
- 单位紧跟数值，`nowrap`

### 血糖

| 单位 | 正常参考（空腹） | 医学可能 |
| --- | --- | --- |
| mmol/L | 3.9 – 6.1 | 1.0 – 40.0 |
| mg/dL | 70 – 110 | 18 – 720 |

- 换算：`mg/dL = mmol/L × 18.0182`（葡萄糖）
- **切换单位必须同时换算数值**。只改标签是最危险的实现错误
- 录入时必须让用户明确选「空腹 / 餐后 2 小时 / 随机」，
  因为三种情况的参考范围不同

### 体温（℃）

| 层级 | 范围 |
| --- | --- |
| 医学可能 | 30.0 – 45.0 |
| 正常参考 | 36.0 – 37.2（腋温） |
| 发热提示 | ≥ 37.3 |
| 危急值 | ≥ 40.0 或 ≤ 35.0 |

- 必须区分测量部位（腋温 / 口温 / 耳温 / 肛温），
  不同部位正常范围相差 0.3–0.5℃
- 保留 1 位小数，输入框宽度约 72px

### 心率（次/分）

| 层级 | 范围 |
| --- | --- |
| 医学可能 | 20 – 300 |
| 正常参考 | 60 – 100 |
| 危急值 | ≥ 150 或 ≤ 40 |

### 体重（kg）/ 身高（cm）

| 指标 | 医学可能 | 说明 |
| --- | --- | --- |
| 体重 | 1 – 400 | 保留 1 位小数 |
| 身高 | 30 – 250 | 保留 1 位小数或整数 |

由身高体重计算的 BMI 要**同时展示计算公式与分级**
（`BMI 24.2，超重`），不要只给一个数字。

## 三、单位换算表

| 指标 | 换算 |
| --- | --- |
| 血糖 | `mg/dL ÷ 18.0182 = mmol/L` |
| 胆固醇 | `mg/dL ÷ 38.67 = mmol/L` |
| 甘油三酯 | `mg/dL ÷ 88.57 = mmol/L` |
| 肌酐 | `mg/dL × 88.4 = μmol/L` |

实现要求：

- 换算用**高精度**中间值，只在展示时 `toFixed`
- 换算后要标注「已换算」，避免用户以为数值被篡改
- 参考范围也要跟着单位换算，不能只换数值

## 四、异常值的交互设计

### 硬报错（超出医学可能范围）

```
输入：血压收缩压 420
提示：收缩压需在 50 – 300 mmHg 之间，请核对
行为：输入框标红，提交按钮禁用
```

文案必须给边界值，不能只写「数值不合法」。

### 软提示（超出正常参考范围）

```
输入：血压收缩压 165
提示：该数值高于正常范围（90 – 139），请确认输入正确
行为：输入框黄色描边；提交时弹出一次确认
```

确认弹窗：

```
血压 165/98 mmHg 高于正常范围
如果是实际测量结果，可以继续保存。

[继续保存]  [返回修改]
```

**关键**：确认按钮文案要明确写「如果是实际测量结果，可以继续保存」，
避免用户误以为系统在阻止他记录。

### 危急值

```
┌────────────────────────────────────────────┐
│ ⚠ 血压 185/120 mmHg 属危急值                │
│ 请立即联系医生或拨打 120                    │
│                          [拨打 120]         │
└────────────────────────────────────────────┘
```

- 位置：页面顶部，`position: sticky; top: 0`，不随滚动消失
- 样式：红色实底（`#c62828`）+ 白色文字 + 图标，**静态无动画**
- 提供**可直接拨号的按钮**（`<a href="tel:120">`）
- 同时记录到数据，不要因为危急就拒绝保存

## 五、常见实现错误

| 错误 | 后果 | 正确做法 |
| --- | --- | --- |
| 用「正常范围」做硬校验 | 患者无法记录真实的异常值 | 硬校验用医学可能范围 |
| 单位换算只改标签 | 用户按错误数值用药，可能造成伤害 | 数值与参考范围一起换算 |
| 血压不校验 SBP > DBP | 录入颠倒的数据，报告无意义 | 交叉校验并报错 |
| 体温不区分测量部位 | 参考范围对不上，误判发热 | 录入时必选部位 |
| 换算用 `parseFloat` 后直接展示 | 出现 `5.600000001` 这类浮点误差 | 计算用高精度，展示用 `toFixed` |
| 危急值只标在表格行内 | 用户看不到，延误处理 | 顶部 sticky 横幅 + 行内标记 |
| 危急值用闪烁动画 | 光敏性癫痫风险 | 静态红色横幅 |
