# 适老化与无障碍规范

医疗健康产品的用户里，60 岁以上占比往往超过三成。
适老化做不好，等于把这三成用户直接排除。

## 一、字号与排版

### 基准值

| 场景 | 字号 | 行高 | 说明 |
| --- | --- | --- | --- |
| 常规模式正文 | 16–18px | 1.6–1.8 | 已高于通用界面的 14px/1.5 |
| 常规模式数值 | 24–36px | 1.2 | 血压、血糖等关键数值 |
| 适老模式正文 | 20–24px | 1.8 | 可开关 |
| 适老模式标题 | 26–32px | 1.4 | |
| 任何模式下的最小值 | 13px | 1.5 | 仅限辅助说明，不可再小 |

### 为什么用 `rem` 而不是 `px`

用户在系统设置里把字号调大时，`rem` 会跟着变，`px` 不会。
医疗产品的用户恰恰是最常去系统设置里调字号的群体。

```css
html { font-size: 100%; }        /* 承接系统设置，不要写死 16px */
body { font-size: 1rem; }
.value { font-size: 1.75rem; }   /* 28px @ 默认 */
```

**例外**：边框宽度、圆角、图标尺寸用 `px` 更合适，
它们不应该随字号缩放（会导致布局崩坏）。

### 文本长度

- 单行文本不超过 **35 个汉字**（适老模式不超过 25 个）。
  超长行会让老年人读串行。
- 段落之间用 1em 以上间距分隔
- 不要用两端对齐（`text-align: justify`），中文两端对齐会产生难看的字间距

## 二、对比度

目标：正文 **≥ 7:1**（WCAG 2.2 AAA），大字号（≥ 24px）可放宽到 4.5:1。

| 用途 | 色值 | 白底对比度 |
| --- | --- | --- |
| 正文 | `#1a1a1a` | ≈ 15.4:1 |
| 次级文字 | `#5a5a5a` | ≈ 7.4:1 |
| 禁用（文字说明替代） | 不用浅灰 | — |
| 危险 | `#c62828` | ≈ 6.4:1（配白字做背景时合格） |

**必须实测**，不要凭肉眼判断。用浏览器 DevTools 的对比度检查，
或任何 WCAG 对比度计算工具。

响应系统设置：

```css
@media (prefers-contrast: more) {
  :root { --text-secondary: #333; }
  .card { border: 2px solid #1a1a1a; }
}
```

## 三、触控与热区

| 元素 | 最小热区 | 推荐 |
| --- | --- | --- |
| 常规模式按钮 | 44×44px | 48×48px |
| 适老模式按钮 | 56×56px | 64×64px |
| 列表项 | 56px 高 | 64px 高 |
| 相邻可点元素间距 | 8px | 16px |

- 热区可以用 `padding` 扩展，不必让视觉元素本身变大
- **不要用纯图标按钮**。老年用户对图标的语义识别率低，
  必须「图标 + 文字」或纯文字
- 手势必须有替代路径：滑动删除 → 同时提供可见的「删除」按钮；
  长按 → 同时提供「更多」按钮

## 四、焦点与读屏

### 焦点

```css
:focus-visible {
  outline: 3px solid #1a1a1a;
  outline-offset: 2px;
}
```

- 焦点环不能删（`outline: none` 是常见的无障碍事故）
- 焦点环宽度 ≥ 2px，与背景对比度 ≥ 3:1
- 弹层打开时把焦点移入，关闭后**归还给触发元素**
- 不要用 `tabindex` 正值调整顺序，顺序应与 DOM 一致

### 语义

- 每个输入框有 `<label for>` 关联，不要只用 placeholder
- 错误提示用 `aria-describedby` 关联，同时设 `aria-invalid="true"`
- 动态更新的内容（校验结果、倒计时）用 `aria-live="polite"`
- 危急值横幅用 `role="alert"`（会立即播报）
- 表格用 `<th scope="col|row">` 标注表头
- 纯装饰图标加 `aria-hidden="true"`

### 读屏验证

至少用 VoiceOver（macOS/iOS）或 TalkBack（Android）跑一遍核心流程：
挂号 → 查看报告 → 记录体征。检查：

- 每个控件都能被朗读出名称与状态
- 顺序符合视觉顺序
- 错误提示在出现时会被播报
- 没有「按钮 按钮 按钮」这类无意义朗读

## 五、动效与动画

```css
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
  }
}
```

- 前庭功能障碍用户开启此设置后，任何位移动画都会引起眩晕
- **禁止闪烁**（每秒 3 次以上的闪烁可能诱发光敏性癫痫）
- 加载动画用不透明度变化而非旋转位移
- 页面转场时长 ≤ 250ms

## 六、适老模式的具体差异

| 维度 | 常规模式 | 适老模式 |
| --- | --- | --- |
| 正文 | 16px | 22px |
| 按钮高度 | 48px | 56–64px |
| 底部 tab 数 | 5 | 3–4 |
| 单屏任务数 | 多个 | 1 个 |
| 次要入口 | 显示 | 隐藏 |
| 横向滚动 | 允许 | 禁止 |
| 图标按钮 | 可接受 | 必须带文字 |
| 表单字段 | 全部展示 | 分步展示，每步 ≤ 3 项 |

### 开关位置

- 放在「我的」页顶部，标签写 **`大字模式`**，不要写「无障碍设置」
  （老年用户不会认为自己是「无障碍用户」）
- 开关状态持久化到本地，且**所有页面生效**
- 首次进入时可以根据系统字号做一次推荐，但不要强制开启

### 适老模式的表单

老年用户填表的最大障碍是「一次看到太多字段」。
处理方式：

- 分步：一屏一个字段或一组字段，底部固定「下一步」
- 每个字段给**真实示例值**，如 `如：13800138000`
- 键盘类型正确（数字字段用 `inputmode="numeric"`）
- 提供「拍照识别」等替代输入方式（身份证、处方单）

## 七、检查清单

- [ ] 正文 ≥ 16px，适老 ≥ 20px，无任何 13px 以下文字
- [ ] 字号用 `rem`，响应系统字号设置
- [ ] 正文对比度 ≥ 7:1（实测）
- [ ] 按钮热区 ≥ 44px（适老 ≥ 56px），相邻间距 ≥ 8px
- [ ] 无纯图标按钮，或图标旁有文字
- [ ] 所有手势都有按钮替代
- [ ] 焦点环可见（≥ 2px，对比度 ≥ 3:1）
- [ ] 所有表单控件有 `<label>`，错误用 `aria-describedby` 关联
- [ ] 动态内容用 `aria-live`，危急值用 `role="alert"`
- [ ] 响应 `prefers-reduced-motion` 与 `prefers-contrast`
- [ ] 无闪烁动画
- [ ] 适老模式下无横向滚动，一屏一个任务
- [ ] 用读屏软件跑通核心流程，无「按钮 按钮」式朗读
- [ ] 适老模式开关标签写「大字模式」，且全站生效

## 八、常见反模式

| 反模式 | 症状 | 修法 |
| --- | --- | --- |
| `html { font-size: 16px }` 写死 | 用户调系统字号无效 | 用 `100%` 承接 |
| 字号用 `px` 且不可调 | 老年用户看不清，只能放大页面导致布局崩坏 | 正文用 `rem` |
| 删除 `outline` | 键盘用户完全找不到焦点 | `:focus-visible` + 自定义焦点环 |
| 用浅灰表示禁用 | 对比度不足，老年用户看不见也读不到 | 用文字说明禁用原因 |
| 纯图标工具栏 | 老年用户不知道图标含义，只能逐个试 | 图标 + 文字 |
| 只有滑动删除 | 老年用户不会滑，无法删除 | 同时提供删除按钮 |
| 适老模式只放大字号 | 热区仍小、信息仍挤，等于没适配 | 四维同时调整 |
| 开关叫「无障碍设置」 | 老年用户心理抵触，不会打开 | 叫「大字模式」 |
| 无 `prefers-reduced-motion` 支持 | 前庭障碍用户眩晕 | 全局降级动效 |
| 用闪烁提示紧急 | 光敏性癫痫风险 | 静态红色横幅 + `role="alert"` |
