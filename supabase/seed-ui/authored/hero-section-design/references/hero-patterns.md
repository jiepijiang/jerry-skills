# 首屏版式与文案模式

按「用户此刻的认知状态」选版式，而不是按审美选。同一产品在不同渠道
（品牌官网 / 搜索广告落地页 / 活动页）的首屏应该长得不一样。

## 四种常见首屏版式

### A. 居中单列（Centered）

- 结构：eyebrow → 主标题 → 副标题 → CTA → 微文案 → 信任条
- 宽度：内容块 `max-width: 680px`，居中
- 适用：品牌认知型产品、SaaS 首页、工具类
- 优点：视线路径最短，移动端几乎不用改
- 风险：连续三四个页面都用这个版式会显得千篇一律
- 高度：内容高度约 480–560px，视口高时靠 padding 撑，**不要拉伸行高**

### B. 左文右图（Split）

- 结构：左 45–50% 文案列，右 50–55% 视觉列（产品截图 / 3D / 插画）
- 断点：`< 1024px` 时上下堆叠，图在文下
- 适用：产品有清晰界面可展示时（后台、App、编辑器）
- 关键：右侧截图要**带设备边框或轻微倾斜**，否则像贴了一张图上去
- 截图高度不要超过首屏可视高度的 80%，否则会被折叠线切一半

### C. 全幅视觉 + 叠字（Full-bleed）

- 结构：背景图/视频铺满，文字叠在上层
- 适用：酒店、旅游、餐饮、地产、汽车 —— 视觉本身就是卖点
- 关键：必须有遮罩，且遮罩要**局部加重**（文字所在区域更暗）
  ```css
  .hero::after {
    content: "";
    position: absolute; inset: 0;
    background: linear-gradient(180deg,
      rgba(0,0,0,.15) 0%,
      rgba(0,0,0,.55) 55%,
      rgba(0,0,0,.75) 100%);
  }
  ```
- 移动端必须换竖版图，横图裁切后主体常被裁掉

### D. 极简宣言（Statement）

- 结构：一句大号主张 + 一个入口，其余全砍
- 字号：桌面 56–80px，行高 1.05–1.15
- 适用：品牌发布页、招聘页、Coming Soon
- 风险：信息不足，转化型页面慎用

## 文案写法

### 主标题

三种可用句式，按可信度从高到低：

1. **结果句**：「把周报从 3 小时压缩到 20 分钟」—— 有数字，最可信
2. **对象 + 能力句**：「给中小团队的合同审阅助手」
3. **动词句**：「重新定义你的记账方式」—— 空，尽量别用

标题里的数字要具体（`3 小时 → 20 分钟`），不要用「大幅提升」「显著降低」。

### 副标题

副标题承担「解释怎么做到」和「限定适用对象」两件事，二选一：

- 机制型：`自动抓取 Git 提交，按项目汇总成周报草稿。`
- 限定型：`为 5–50 人的技术团队设计，支持自建部署。`

**反面**：副标题复述标题。
标题「让协作更高效」，副标题「提升团队协作效率」—— 等于浪费一行。

### CTA 文案

- 主 CTA 用「动词 + 结果」：`免费开始使用`、`生成我的报告`、`预约演示`
- 避免：`提交`、`确定`、`了解更多`（无收益预期）
- 避免：`立即免费注册并开始使用您的账户`（超过 10 字，按钮会换行）
- 次 CTA 用「低承诺动作」：`看 2 分钟演示`、`下载白皮书`

### 微文案（零风险提示）

放在主 CTA 下方 8–16px，字号 13–14px，颜色比副标题更浅：

| 行业 | 有效微文案 |
| --- | --- |
| SaaS | 无需信用卡 · 14 天免费试用 |
| 电商 | 7 天无理由退货 · 顺丰包邮 |
| 金融 | 银行级加密 · 资金由第三方存管 |
| 医疗 | 三甲医院医师审核 · 隐私加密 |

## 信任证明条

首屏底部的「一行证明」，三种形态，按可信度排序：

1. **Logo 墙**：5–6 个知名客户 Logo，灰度处理（`filter: grayscale(1); opacity: .6`）
   —— 颜色太鲜艳会抢主 CTA 的注意力
2. **数据背书**：`已服务 12,000+ 团队`、`处理 4.2 亿笔交易` —— 数字要真实且具体
3. **评分/媒体**：`App Store 4.8 分`、`36氪报道` —— 需附来源

**不要**在首屏同时放 Logo 墙和数据，会显得拥挤。选一个，另一个放第二屏。

## 首屏与第二屏的衔接

首屏底部露出的内容量决定用户是否知道「下面还有」：

- 满屏首屏（`100dvh`）：必须让第 2 屏内容露出 8–15%，
  否则用户以为页面到底了。做法是首屏 `min-height: calc(100dvh - 80px)`，
  或给下一区块一个 `padding-top` 让标题露出。
- 非满屏首屏：天然露出，无需处理。

可以在首屏底部加一个向下箭头（`↓`，24px，`opacity: .5`，
带 2s 循环的 8px 上下位移动画，且 `reduced-motion` 下静止）。
