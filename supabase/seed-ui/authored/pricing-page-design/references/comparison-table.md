# 功能对比表的组织与移动端处理

对比表是定价页里最长的一块，也是最容易做砸的一块。
它的目标不是「列全所有功能」，而是**让用户快速确认「我要的功能在哪一档」**。

## 一、分组

按功能域分组，每组给一个语义标题。推荐的分组顺序（按用户关心度递减）：

1. **核心能力**（这个产品是干嘛的）—— 必放最前
2. **协作**（多人场景）
3. **集成**（连了哪些外部系统）
4. **安全与合规**（企业采购必看）
5. **支持**（响应时间、渠道）

每组 **3–6 行**。超过 6 行说明这个组还可以再拆，或里面混了不重要的功能。

## 二、行内取值的三种类型

| 类型 | 写法 | 适用 |
| --- | --- | --- |
| 布尔 | `✓` / `—` | 有/无即可的功能 |
| 数值 | `10 GB` / `5 个` / `1,000 次/月` | 用量类，**必须带单位** |
| 文本 | `邮件` / `邮件 + 工单` / `专属客户成功` | 支持等级类 |

注意：

- 缺失项写灰色 `—`，不要留空。留空会让用户以为加载失败
- 布尔值不要用 `是/否` 文字，视觉扫描效率低
- 数值型一定要带单位。只写 `10` 用户不知道是 10GB 还是 10 个

## 三、高亮当前档位列

用户从上面点进来时通常已经倾向某一档，要让对应列**竖着也能一眼跟上**：

```css
.compare th:nth-child(3),       /* 推荐档列 */
.compare td:nth-child(3) {
  background: color-mix(in srgb, var(--brand) 5%, transparent);
  border-inline: 1px solid color-mix(in srgb, var(--brand) 25%, transparent);
}
```

`color-mix()` 是原生 CSS 函数（Chrome 111+ / Safari 16.2+）。
不支持时可退化为一个手写的浅色变量，不要用 JS 算颜色。

## 四、长表格的可用性

- 表头 `position: sticky; top: 64px`（64 = 导航高度），否则滚到第 20 行就忘了列对应谁
- 第一列（功能名）也 `sticky; left: 0`，横向滚动时保持可见
- 表格底部**再放一次三个 CTA**，用户看完差异后正好在此决策
- 每列顶部重复档位名 + 价格，不要只写「基础版」

## 五、移动端：不做横向滚动表格

移动端横向滚动表格的滑出率通常低于 40%，大多数用户根本不会滑。
正确做法是**每档一个可折叠区块**：

```html
<details class="plan-accordion" open>
  <summary>
    <span>专业版</span>
    <span class="plan-accordion__price">¥199/月</span>
  </summary>
  <ul>
    <li><span>成员上限</span><span>20</span></li>
    <li><span>存储</span><span>100 GB</span></li>
    <li><span>审计日志</span><span class="muted">—</span></li>
  </ul>
  <a class="btn btn--primary" href="/signup?plan=pro">开始使用</a>
</details>
```

要点：

- 推荐档默认 `open`，其余默认收起 —— 页面打开时就有一个展开的锚点
- `summary` 里同时显示档位名和价格，用户不展开也知道价
- 每个折叠块底部放一个 CTA，用户展开哪档就在哪档决策
- 用原生 `<details>` 元素，自带键盘可达性和读屏支持，不需要自己实现 aria

## 六、常见反模式

| 反模式 | 症状 | 修法 |
| --- | --- | --- |
| 40 行平铺无分组 | 用户滑两屏后迷路，直接跳到底部找按钮 | 分 5 组，每组 3–6 行 |
| 把「所有档都有」的功能放最前面 | 前 8 行看不出差异，用户以为三档一样 | 差异项前置，公共项沉底 |
| 用 `∞` 表示不限 | 部分用户理解成「无此功能」或「错误」 | 写「不限」 |
| 对比表里塞营销话术 | 一行写 20 个字，表格宽度爆炸 | 功能名 ≤ 12 字，细节放 tooltip |
| 移动端横向滚动 | 用户滑一次就放弃，只看得到第一档 | 改折叠列表，推荐档默认展开 |
| 表头不 sticky | 滚到第 15 行时忘记列顺序，看错档位 | 表头 sticky，`top` = 导航高度 |
