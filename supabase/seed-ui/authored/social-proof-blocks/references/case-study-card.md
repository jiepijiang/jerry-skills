# 案例研究卡片与案例详情页

证言是「一句话证明」，案例是「一段过程证明」。
案例承担的是**深度说服**，通常给已经在对比阶段的用户看，
所以它要经得起细读，而不是用来扫一眼。

## 一、卡片（列表页）

三段式结构，缺一不可：

```html
<a class="case-card" href="/cases/yunque">
  <header class="case-card__head">
    <img src="/logos/yunque.svg" alt="云雀科技" height="24">
    <span class="case-card__industry">SaaS · 200 人</span>
  </header>
  <h3 class="case-card__title">把新客注册转化从 3.1% 提到 5.4%</h3>
  <p class="case-card__summary">
    表单从 11 个字段砍到 4 个，其余改成渐进式补全，投放不变的情况下
    两周内转化提升 74%。
  </p>
  <ul class="case-card__metrics">
    <li><strong>+74%</strong><span>注册转化</span></li>
    <li><strong>−58%</strong><span>表单放弃率</span></li>
  </ul>
  <span class="case-card__cta">阅读案例 →</span>
</a>
```

字段规范：

| 字段 | 长度 | 说明 |
| --- | --- | --- |
| 客户 Logo | 高 20–24px | 灰度或原色，需授权 |
| 行业 + 规模 | 8–16 字 | `SaaS · 200 人` 帮读者判断可比性 |
| 标题 | 18–30 字 | **用结果数字做标题**，不要写「云雀科技案例」 |
| 摘要 | 40–80 字 | 说明做了什么 |
| 指标 | 2–3 个 | 每个带 `+/−` 号和单位 |
| CTA | 固定文案 | `阅读案例 →` |

**标题必须带数字**。「云雀科技的数字化转型之路」这种标题没人点，
`把新客注册转化从 3.1% 提到 5.4%` 才有信息量。

## 二、卡片布局

- 桌面：3 列，每张宽 ≥ 320px，`min-height: 280px`
- 平板：2 列
- 移动：1 列，最多展示 3 张，其余进「查看全部案例」
- 卡片整体可点（外层 `<a>`），但**卡片内的「阅读案例」也要有 hover 反馈**，
  否则用户不知道整张卡可点
- 用 `align-items: stretch` 让同行卡片等高，内部用 `margin-top: auto`
  把指标和 CTA 推到底部对齐

## 三、详情页结构

一个案例详情页按下面的顺序组织，每部分都可独立成立：

1. **头部**：客户 Logo、行业、规模、标题（带数字）、2–3 个核心指标
2. **背景**：客户遇到的具体问题，2–3 段，每段 ≤ 100 字
3. **为什么选我们**：对比过的 1–2 个替代方案，说明决策理由
4. **实施过程**：时间线（`第 1 周 / 第 3 周 / 第 2 个月`），
   写清遇到的阻力与怎么解决 —— 这一节最容易建立可信度
5. **结果**：用图表展示指标变化，**必须标数据口径和统计周期**
6. **客户原话**：2–3 条证言，可以比首页的更长
7. **下一步 CTA**：`预约演示` 或 `查看定价`

## 四、结果图表

- 用折线或柱状展示「前后对比」，不要用饼图
- Y 轴**不要从 0 开始截断再夸大差异**（这是误导性可视化）
- 每个图表下方一行小字：`数据来源：客户后台，2026-06 至 2026-08`
- 只有一个数值时，用大数字块而非图表：
  `+74%` / `注册转化提升`
- 图表配色用单一品牌色，不要用彩虹色

## 五、可信度细节

这些细节决定了案例是「真实复盘」还是「营销稿」：

- 写清**实施周期**（`上线用了 3 周`），不写会显得像魔法
- 承认**一个限制或取舍**（`初期需要手动导入历史数据`）——
  有缺点的案例更可信
- 客户方**具名到角色**（`技术负责人 李维`），至少给到职位
- 结果数字给出**对比基线和周期**（`相比上线前 30 天均值`）
- 提供**客户官网链接**（如客户同意），读者可以自己核实

## 六、案例页与首页的关系

- 首页只放 3 张卡片，承担「证明有真实客户」的作用
- 完整案例放 `/cases/<slug>`，可被搜索引擎收录
- 每张卡片的标题和 URL slug 都带客户名与指标，
  这样搜索「云雀科技 注册转化」也能命中
- 案例页底部推荐 2 个**同行业**的其他案例，提升继续阅读率

## 七、常见反模式

| 反模式 | 症状 | 修法 |
| --- | --- | --- |
| 标题写「XX 公司案例」 | 没有信息量，点击率极低 | 用结果数字做标题 |
| 只有结论没有过程 | 用户怀疑数字来源 | 补实施时间线，含阻力与解决 |
| 全是成功没有取舍 | 像营销稿，可信度下降 | 写一条真实的限制或初期成本 |
| 图表 Y 轴截断 | 被识破后整页可信度崩塌 | Y 轴从 0 起，或明确标注截断 |
| 指标不带周期 | 「提升 74%」不知道是多长时间 | 写 `两周内`、`相比前 30 天` |
| 案例只有 1 个还挂在首页 | 显得客户很少 | 少于 3 个时，首页改用证言 + Logo 墙 |
